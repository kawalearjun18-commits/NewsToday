# Search Console and Bing Webmaster Steps

**Status: pending human**

1. Deploy the production HTTPS domain and confirm the preferred hostname.
2. In Google Search Console, add the domain property, verify DNS ownership, submit `/sitemap-index.xml`, inspect `/en/` and `/hi/`, and request indexing for priority pages.
3. In Bing Webmaster Tools, import or verify the domain, submit the sitemap index, inspect representative language URLs, and enable IndexNow only after reviewing its deployment key handling.
4. Monitor coverage, enhancements, News surfaces, Core Web Vitals, hreflang, and crawl errors.
5. Record verification dates and owners in the release log. No submission is claimed by this project.
